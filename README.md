# Автоматический отчёт по аварийным ситуациям на сети

Сбор сообщений `ecus_bot` из Telegram-группы с подчатами, дедупликация по
Номеру ПБ, формирование Excel-отчёта из 9 листов и эскалация в Telegram при
простое более 8 часов.

Два варианта сборщика данных — выберите один:

| Вариант | Файл | Как получает данные | Плюсы / минусы |
|---|---|---|---|
| **Бот (рекомендуется)** | `bot_listener.py` | Слушает группу в реальном времени через Bot API, копит сообщения в `raw_messages.jsonl` | Просто настроить (BotFather, без my.telegram.org). Минус: не видит историю до запуска, должен работать непрерывно |
| Личный аккаунт | `fetch_telegram.py` | Выгружает историю за N дней через Telethon (MTProto) | Видит всю историю, разовый запуск по расписанию. Минус: сложнее настроить (my.telegram.org) |

## Вариант с ботом (bot_listener.py)

### 1. Установка

```bash
pip install -r requirements.txt
cp config_local.example.py config_local.py
```

`config_local.py` — ваш личный файл с секретами, он в `.gitignore` и никогда
не попадёт в git-репозиторий. Все реальные значения (токен, chat_id) нужно
вписывать именно туда, а не в `bot_listener.py`/`fetch_telegram.py` напрямую.

### 2. Создать бота

1. В Telegram написать **@BotFather** → `/newbot`.
2. Задать имя и username бота (username должен заканчиваться на `bot`, например `dtprs_report_bot`).
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — вписать в `BOT_TOKEN` в `config_local.py`.

### 3. Добавить бота в группу и сделать администратором

**Важно:** `ecus_bot` — тоже бот. Telegram по умолчанию не доставляет ботам
сообщения от других ботов в группе, даже если отключить Group Privacy у
BotFather. Единственный надёжный способ получать сообщения `ecus_bot` —
**сделать нашего бота администратором** группы-источника (права можно
выдать минимальные, само наличие админ-статуса снимает ограничение).

Как сделать: Настройки группы → Администраторы → Добавить администратора →
выбрать созданного бота.

### 4. Узнать chat_id группы (режим обнаружения)

Оставить `SOURCE_CHAT_ID` не заданным в `config_local.py` (или закомментировать
строку) и запустить:

```bash
python bot_listener.py
```

Написать любое сообщение в группе (или дождаться очередного обновления от
`ecus_bot`) — в консоли появится строка вида:

```
[ОБНАРУЖЕНИЕ] chat_id=-1001234567890  chat_title='Minor ПБ (оповещ...)'  thread_id=42
```

Скопировать `chat_id` (число, обычно отрицательное для групп) в
`SOURCE_CHAT_ID` в `config_local.py`.

### 5. Заполнить остальную конфигурацию

В `config_local.py`:
- `SOURCE_CHAT_ID` — из шага 4.
- `ALERT_CHAT` — chat_id или `@username` чата для уведомлений об эскалации
  (бот должен быть добавлен и туда, либо это может быть тот же chat_id,
  либо `"me"`-эквивалент — для ботов это ваш личный чат с ботом: напишите
  боту `/start` в личку, затем через тот же режим обнаружения узнайте свой
  личный chat_id).
- `REPORT_INTERVAL_MINUTES` (в `bot_listener.py`, необязательно) — как часто
  пересобирать отчёт (по умолчанию 60 минут).

### 6. Запустить

```bash
python bot_listener.py
```

Бот должен **работать непрерывно** — он копит сообщения по мере
поступления и раз в `REPORT_INTERVAL_MINUTES` минут пересобирает
`avariynyy_otchet.xlsx`. Если процесс останавливается, все сообщения,
пришедшие за это время, будут потеряны безвозвратно (в отличие от варианта
с личным аккаунтом).

Для постоянной работы на Windows проще всего:
- оставить открытым окно консоли, либо
- запускать через Планировщик заданий с триггером «При входе в систему» и
  без ограничения по времени работы, либо
- обернуть в службу Windows (например, через NSSM).

## Вариант с личным аккаунтом (fetch_telegram.py)

Требует `API_ID`/`API_HASH` с https://my.telegram.org и одноразовую
авторизацию личного аккаунта через Telethon. Даёт доступ к истории
сообщений за произвольный период (`CONFIG["DAYS_BACK"]`). Подробности —
в комментариях внутри `fetch_telegram.py`.

```bash
python fetch_telegram.py --demo   # тестовый прогон без Telegram
python fetch_telegram.py          # обычный запуск
```

## Файлы

| Файл | Назначение |
|------|------------|
| `parser.py` | Разбор текста сообщений `ecus_bot` в структурированные записи, дедупликация |
| `report_builder.py` | Агрегация данных, генерация `.xlsx` (9 листов, диаграммы, форматирование), текст эскалации |
| `storage.py` | Персистентное хранилище сырых записей (JSON Lines) для варианта с ботом |
| `bot_listener.py` | Сборщик данных через Bot API — слушает группу непрерывно, копит данные, строит отчёт по расписанию |
| `fetch_telegram.py` | Альтернативный сборщик через Telethon (личный аккаунт) — разовая выгрузка истории за период |
